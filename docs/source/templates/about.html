About

LineDream was created to make creating vector graphics simple and intuitive. Every primitive has its own style, positioning and transformation methods, so there is almost no global state to manage.

It was originally built to make art for a pen plotter, which is why it outputs SVG. The object structure underneath isn't tied to SVG, so it could support other renderers too.

The library was created and is maintained by Marc Leonard. Bug reports, ideas and pull requests are welcome on GitHub.
