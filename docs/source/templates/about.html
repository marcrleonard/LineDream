About

Why LineDream?

LineDream was created to make creating vector graphics simple and intuitive. Though the library is heavily inspired by P5 and Processing's capabilities, the goal is to allow primitives to have their own style, positioning and transformation methods.

It was originally built to make art for a pen plotter, so it outputs SVG: a format that keeps every line a line, all the way to the paper. The object structure underneath is renderer-agnostic and could drive other targets too.

The library was created and is maintained by Marc Leonard. Bug reports, ideas and pull requests are welcome on GitHub.
